# Джарвис · маленький прототип

Локальное распознавание русской речи через Vosk, текстовый ввод, заметки,
список дел, таймеры, напоминания, запуск выбранных программ, погода и новости
в Chrome. Запускается вручную. Подписки, API-ключи и языковая модель не нужны.

## Первый запуск в Windows

1. Установи обычный **Python 3.13, 64-bit** с python.org. Оставь `pip`, `Tcl/Tk`
   и включи **Add python.exe to PATH**. Поддерживается также Python 3.10–3.12.
2. Запусти **`setup.cmd`**. Он создаст `.venv`, установит библиотеки и скачает
   русскую модель Vosk (~45 МБ) в папку проекта. Интернет нужен для установки.
   Если ZIP уже лежит в папке проекта, `models` или обычной папке `Downloads`,
   установщик использует его. Уже распакованную модель повторно не скачивает.
   При недоступности сервера Vosk используется закреплённое зеркало Rhasspy
   на Hugging Face; в обоих случаях проверяется SHA-256 архива.
3. Открой **`run.cmd`**. Это обычный режим с микрофоном. Автозапуска нет.
4. В меню **«Настройки»** укажи город для погоды. Chrome обычно обнаруживается
   автоматически; при необходимости выбери `chrome.exe` вручную.
5. Скажи **«Джарвис»**, сделай короткую паузу до зелёного индикатора и сигнала.
   Теперь можно сказать **«Покажи погоду»** или **«Новости про нейросети»**.
6. Скажи **«Джарвис, спасибо»** для возврата в ожидание.

В текстовой строке снизу можно сразу вводить команды **без кодового слова**.
Она работает, даже если микрофон ещё загружается или недоступен. Ответы и текст
заметок появляются в истории окна; озвучивания пока нет. В меню **«Мои данные»**
доступны заметки, дела, таймеры, напоминания и выбранные программы.

При первом запуске создаётся `config.json`. Город заранее не предполагается:
если он пустой, команда погоды уточнит город. Ответ применяется к одному запросу;
постоянный город задаётся в настройках. Изменение микрофона и модели требует
перезапуска приложения. Город, Chrome и звуковой сигнал применяются сразу.

## Команды

| Фраза | Результат |
| --- | --- |
| «Джарвис» или кнопка «Активировать» | Зелёный индикатор, ожидание команды |
| «Джарвис, покажи погоду» | Активация и команда одной законченной фразой |
| «Покажи погоду», «Какая сегодня погода?», «Открой прогноз» | Поиск прогноза для настроенного города |
| «Погода в Москве на завтра» | Поиск прогноза с названным городом и датой |
| «Новости об искусстве», «Покажи новости про нейросети» | Вкладка Google с результатами поиска новостей |
| «Покажи новости» → «Про музыку» | Уточнение темы, затем вкладка новостей |
| «Отмена» | Сброс уточняющего вопроса; помощник остаётся активным |
| «Джарвис, спасибо», «Джарвис, стоп» | Возврат в ожидание обращения |
| «Создай заметку: Купить корм, 2 пакета.» | Сохранение текста с номером заметки |
| «Покажи заметки», «Прочитай заметку 1» | Список или полный текст в окне |
| «Добавь дело записаться к врачу», «Добавь в список дел купить чай» | Новое дело с номером |
| «Покажи список дел», «Отметь дело 1» | Список и отметка о выполнении |
| «Таймер на пять минут чай», «Поставь таймер на 1 час 30 минут» | Таймер с отдельным уведомлением и сигналом |
| «Напомни через десять минут проверить духовку» | Напоминание с текстом через заданный срок |
| «Напомни завтра в 09:30 позвонить» | Напоминание на местное время Windows |
| «Напомни 25.10.2026 в 18:00 забрать заказ» | Напоминание на конкретную будущую дату |
| «Покажи таймеры», «Покажи напоминания» | Список ожидающих записей с номерами |
| «Отмени таймер 1», «Отмени напоминание 2» | Отмена записи по номеру |
| «Покажи программы», «Открой программу Блокнот», «Запусти Блокнот» | Список или запуск заранее выбранной программы |

**Меню «Помощь»** содержит примеры. Если сказать «Создай заметку» или «Добавь
дело» без текста, Джарвис задаст вопрос и примет следующую фразу. «Отмена»,
повторное обращение и «Джарвис, спасибо» сбрасывают уточнение.

## Заметки, дела и напоминания — пункт 3 плана

Заметки и дела сразу записываются в локальную базу `data/jarvis.sqlite3`.
Регистр, знаки препинания и переносы строк сохраняются такими, какими их передал
текстовый ввод или распознаватель. Номера постоянные, выполненные дела остаются
в списке. В меню «Мои данные» можно просмотреть полный текст, создать записи
кнопками и отметить дело выполненным.

Таймеры и напоминания также сохраняются сразу. Сроки можно задавать цифрами
и словами: «пять минут», «полчаса», «один час и тридцать минут». Для календарного
времени используются **ЧЧ:ММ**, «сегодня», «завтра», «послезавтра» либо дата
**ДД.ММ.ГГГГ**. Прошедшие и некорректные даты не принимаются. Напоминанию нужен
текст; у таймера он необязателен.

Пример проверки:

1. Введи «Напомни через минуту проверить духовку».
2. Закрой Джарвиса крестиком и подожди больше минуты.
3. Запусти `run.cmd` — появится окно с **пропущенным напоминанием**.
4. Закрой и снова запусти приложение — уже показанное напоминание повторно
   не появится. Его состояние видно в меню «Мои данные».

Проверка сроков выполняется примерно раз в секунду, независимо от активации
голоса. В режиме ожидания имени уведомления продолжают появляться, звучит
системный сигнал. Они не прерывают ввод команды. После сна ноутбука наступившие
напоминания показываются при возобновлении работы приложения.

**Пока приложение закрыто или ноутбук спит, уведомлений нет.** Пропущенные
таймеры и напоминания показываются при следующем запуске. Фоновой службы
и автозапуска на этом этапе нет. Уже показанные и отменённые записи остаются
в окне данных со своим состоянием.

## Выбранные программы

Открой **«Мои данные → Программы → Добавить программу»**, задай короткое название
(например, «Блокнот») и выбери настоящий `.exe`-файл. После этого работают
«Открой программу Блокнот», «Открой Блокнот» и «Запусти Блокнот». Список выбранных
программ сохраняется после закрытия. «Убрать из списка» удаляет только запись
Джарвиса; файл программы остаётся на месте.

По голосовой команде запускается только выбранный исполняемый файл, без
параметров командной строки. Произвольные пути, скрипты и команды оболочки
не исполняются. Если программа перемещена или удалена, нужно заново добавить
её файл. Успешный ответ означает, что Windows приняла команду запуска;
дальнейшую работу программы Джарвис не проверяет.

После каждой команды активный режим сохраняется до благодарности или нажатия
«В ожидание». Другие фразы в режиме ожидания не исполняются. Имя должно стоять
в начале фразы. Неизвестные команды показывают подсказку, ничего не запускают.
Погода и новости **открываются в браузере**; чтения страниц и озвучивания сводок
в этой версии ещё нет. Программа сообщает о передаче адреса Chrome, но не
проверяет, загрузился ли сайт или есть ли интернет.

## Что означает остановка

- **«Джарвис, спасибо» / кнопка «В ожидание»**: закончить активный диалог.
  Микрофон остаётся открытым, Vosk локально распознаёт звук для поиска имени.
  Уже открытые вкладки остаются. Запуск вкладки, уже переданный Chrome, не отменяется.
  Таймеры и напоминания продолжают работать; выбранные программы не закрываются.
- **Крестик / меню «Выход»**: полное завершение с освобождением микрофона.
  После завершения кодовое слово не работает до ручного запуска.
- **Серый индикатор**: ожидание имени. **Зелёный**: приём команд.
  **Жёлтый**: загрузка. **Красный**: голосовой ввод недоступен.

Распознавание законченной фразы ждёт паузы, поэтому индикатор меняется не мгновенно.
Промежуточные гипотезы не запускают действия: «Джарвис, спасибо» всегда имеет
приоритет над активацией. Качество распознавания зависит от микрофона и фона;
это первый детектор через ASR, без отдельной обученной wake-word модели.
Он не различает владельца и других людей или записи с обращением.

## Логи и данные

- `config.json`: город, путь к модели и Chrome, выбранный микрофон, кодовое слово.
- `models/`: локальная модель распознавания.
- `data/jarvis.sqlite3`: заметки, дела, сроки и состояния таймеров и напоминаний,
  названия и пути выбранных программ. База не добавляется в Git.
- `logs/jarvis.log` и до трёх архивных журналов: время, переключения режима,
  **законченные команды в активном режиме**, текстовые команды, результаты
  личных команд, уведомления, адреса поиска, ошибки.
  Каждый файл ограничен примерно 2 МБ. Журналы могут содержать личные темы поиска.
- **Меню «Логи → Открыть журнал»**: отдельное окно, обновляется автоматически.
- **«Логи → Выгрузить ZIP»**: сохраняет журналы в выбранное место. Ничего не отправляет.
  База данных в архив логов не входит. Для резервной копии закрой приложение
  и скопируй `data/jarvis.sqlite3` в выбранное место.

Звук хранится только в небольшом временном буфере в оперативной памяти; аудиофайлы
не создаются. Обычная речь в ожидании не попадает в экран или журналы. Во время
работы приложение само не обращается к облачному распознаванию. Поисковый текст
передаётся Google через Chrome; история и синхронизация браузера регулируются
настройками Chrome. Эти команды не требуют дополнительного подтверждения.
Заметки и дела меняют только собственную базу Джарвиса. Отправка сообщений,
редактирование произвольных файлов и системные команды не реализованы.

## Запуск из терминала

Команды выполняются из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tools\download_model.py
.\.venv\Scripts\python.exe main.py
```

Установка модели из скачанного архива в другом месте:

```powershell
.\.venv\Scripts\python.exe tools\download_model.py --archive "D:\Загрузки\vosk-model-small-ru-0.22.zip"
```

Режим **`demo.cmd`** или `python main.py --demo` показывает то же окно с текстовым
вводом. В нём **микрофон выключен, Chrome и выбранные программы не запускаются**:
предполагаемые действия записываются в лог. Заметки, дела и напоминания работают
на временной базе в памяти, которая исчезает при закрытии; настоящая база не
меняется. Он работает даже без Vosk и модели, нужен только Python с Tkinter.

Проверка установки без открытия микрофона и браузера:

```powershell
.\.venv\Scripts\python.exe main.py --check
.\.venv\Scripts\python.exe main.py --list-microphones
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют диалог, сохранение и повторное открытие базы, пропущенные
напоминания, отмену таймеров, разбор времени, выбор программ, поисковые адреса,
ошибки Chrome, буферизацию и интерфейс. Реальная запись речи, открытие вкладок
и запуск выбранных программ в тестах не выполняются.

## Если не работает

- **Нет доступа к микрофону:** разреши доступ к микрофону для классических
  приложений в настройках конфиденциальности Windows, выбери устройство в меню
  «Настройки», закрой и запусти приложение снова.
- **Не найдена модель:** распакованная папка должна содержать `am/final.mdl`,
  `conf` и `graph`. Выбирай саму папку модели, а не её родителя.
- **Не запускается окно:** у Python должны быть установлены Tcl/Tk.
- **Не найден Chrome:** укажи путь к его исполняемому файлу в настройках.
- **Не распознаёт слово:** попробуй тихую комнату и короткую паузу после имени;
  посмотри журнал. Кнопка активации позволяет отдельно проверить команды.
- **Ошибка установки:** повтори команду из терминала и сохрани её вывод;
  ошибки запуска приложения находятся в `logs`.

Основные файлы: `main.py` — запуск, `jarvis/ui.py` — окно, `jarvis/voice.py` —
микрофон и Vosk, `jarvis/commands.py` — диалог, `jarvis/browser.py` — Chrome,
`jarvis/personal.py` — личные команды и SQLite, `jarvis/schedule.py` — время,
`jarvis/programs.py` — запуск программ, `jarvis/data_ui.py` — окно данных.
